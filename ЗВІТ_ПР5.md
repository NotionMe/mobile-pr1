## Мета роботи

Інтегрувати глобальний стейт-менеджер (Zustand) і персистентне локальне сховище (AsyncStorage) в існуючий React Native проєкт для збереження даних користувача, налаштувань та списку рослин.

---

## Хід роботи

### 1. Встановлення залежностей

Встановлено необхідні пакети:
```bash
npx expo install zustand @react-native-async-storage/async-storage
```

### 2. Створення глобальних сховищ (stores)

Створено три Zustand stores з підтримкою персистентності через AsyncStorage:

#### 2.1. `useUserStore` (`src/stores/useUserStore.ts`)
- Зберігає дані авторизованого користувача (id, username, email, fullName, role, token)
- Підтримує режим `sessionOnly` для відключення збереження на пристрій
- Методи: `setUser`, `setLoading`, `setSessionOnly`, `logout`

#### 2.2. `useSettingsStore` (`src/stores/useSettingsStore.ts`)
- Зберігає налаштування додатку: тема, відображення деталей, ім'я садівника, девіз саду, фільтри
- Підтримує режим `sessionOnly`
- Методи: `updateSettings`, `setSessionOnly`

#### 2.3. `usePlantsStore` (`src/stores/usePlantsStore.ts`)
- Зберігає список рослин користувача
- Підтримує режим `sessionOnly`
- Методи: `addPlant`, `deletePlant`, `setSessionOnly`

### 3. Інтеграція сховищ у Context API

Оновлено існуючі Context провайдери для використання Zustand stores замість локального `useState`:

- **AuthContext** → використовує `useUserStore`
- **AppSettingsContext** → використовує `useSettingsStore`
- **PlantsContext** → використовує `usePlantsStore`

Це дозволило зберегти існуючий API для компонентів, але додати персистентність даних.

### 4. Додавання UI-перемикача "Режим тільки на сесію"

На екрані налаштувань (`app/(tabs)/settings.tsx`) додано новий Switch:

```tsx
<View style={styles.settingRow}>
  <View style={styles.settingTextBox}>
    <Text style={[styles.settingTitle, { color: colors.text }]}>
      Режим "тільки на сесію"
    </Text>
    <Text style={[styles.settingDescription, { color: colors.textMuted }]}>
      Не зберігати дані на пристрій після закриття додатку
    </Text>
  </View>
  <Switch value={sessionOnly} onValueChange={toggleSessionOnly} />
</View>
```

При увімкненні цього режиму:
- Дані не зберігаються в AsyncStorage
- Після закриття додатку всі зміни втрачаються
- При вимкненні режиму дані знову починають зберігатися

### 5. Логіка персистентності

Кожен store використовує middleware `persist` з Zustand:

```typescript
persist(
  (set) => ({ /* state and actions */ }),
  {
    name: 'storage-name',
    storage: createJSONStorage(() => AsyncStorage),
    partialize: (state) => {
      if (state.sessionOnly) {
        return { sessionOnly: state.sessionOnly };
      }
      return { /* fields to persist */ };
    },
  }
)
```

Функція `partialize` визначає, які поля зберігати:
- Якщо `sessionOnly === true` → зберігається тільки сам прапорець
- Якщо `sessionOnly === false` → зберігаються всі дані

### 6. Тестування

Додаток успішно запущено через `npx expo start --port 8082`.

**Сценарії тестування:**

1. **Збереження даних:**
   - Авторизуватися в додатку
   - Змінити налаштування (тема, ім'я садівника)
   - Додати/видалити рослини
   - Закрити додаток
   - Відкрити знову → дані збережені ✓

2. **Режим "тільки на сесію":**
   - Увімкнути перемикач "Режим тільки на сесію"
   - Змінити налаштування
   - Закрити додаток
   - Відкрити знову → зміни скинуті, дані не збережені ✓

3. **Глобальна реактивність:**
   - Зміни в одному компоненті відображаються на всіх екранах ✓

## Висновки

У ході виконання практичної роботи №5 успішно інтегровано глобальний стейт-менеджер Zustand та локальне сховище AsyncStorage в React Native додаток. Реалізовано три сховища для користувача, налаштувань та списку рослин з підтримкою автоматичного збереження даних на пристрій.

Додано режим "тільки на сесію", який дозволяє користувачу вимкнути персистентність даних. Всі зміни стану тепер глобально реактивні та зберігаються між сесіями додатку.

Zustand показав себе як простий та ефективний інструмент для керування станом, а middleware `persist` значно спростив інтеграцію з AsyncStorage порівняно з ручною реалізацією.
